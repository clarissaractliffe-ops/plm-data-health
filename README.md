# PLM Data Health

Prototype that checks a PLM material export for empty fields (price, MOQ, lead time…), shows the gaps by field and by supplier, and builds a chase list.

- Opens on **invented sample data**.
- **Load PLM export** accepts .xlsx, .xls or .csv. The file is read in the browser and is never uploaded.
- Single static file (`index.html`), no server needed.
